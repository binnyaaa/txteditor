# 토막글 조판기

글을 붙여넣으면 SNS에 올리기 좋은 이미지로 나눠주는 웹 도구입니다.
설치 없이 브라우저에서 바로 쓸 수 있어요.

## 기능

- 글을 장마다 위아래 가운데에 맞춰 배치
- 한 장 최대 글자 수 지정 (기본 1000자, 넘치면 다음 장으로)
- 글자 크기 · 자간 · 줄 간격 · 문단 간격 조절
- 좌우 / 위아래 여백 조절
- 정렬(양쪽 · 왼쪽 · 가운데), 문단 첫 줄 들여쓰기
- 비율: 4:5 · 1:1 · 3:4 · 9:16 (가로 1080px)
- 페이지 수 · 크레딧 표시 켜고 끄기
- 배경색 · 글자색 변경
- PNG로 한 장씩 저장, 또는 전체를 zip으로 저장

## 글꼴

- **웹 글꼴**: 나눔명조, 고운바탕, 본명조, 함렛, 고운돋움, 본고딕
- **내 컴퓨터 글꼴**: 설치된 글꼴 이름을 입력해서 사용 (크롬 · 엣지에서는 목록 불러오기 가능)
- **글꼴 파일 올리기**: `.ttf` `.otf` `.woff` `.woff2` (새로고침하면 다시 올려야 함)

> 유료 글꼴은 이미지 배포가 허용되는지 라이선스를 확인해 주세요.

## 사용법

1. 본문 칸에 글을 붙여넣기
2. 글꼴 · 크기 · 여백 등을 조절하며 오른쪽 미리보기 확인
3. `PNG 저장` 또는 `전체 저장 (zip)`

설정은 브라우저에 자동 저장됩니다.

## 배포

`index.html` 파일 하나로 동작합니다.
GitHub 저장소에 올린 뒤 **Settings → Pages**에서 브랜치를 선택하면 바로 사이트가 열립니다.
